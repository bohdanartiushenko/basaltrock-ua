# basaltrock-ua

Україномовна локальна база знань (з ШІ) [basaltrock](../basaltrock). 


## Використання

```bash
make up     BASALTROCK=/path/to/documents`
make down
```
## Змінні

| Var | Default |
|---|---|
| `BASALTROCK` | `../basaltrock` |
| `DATA_FOLDER` | `data` |
| `DOC_ANSI_CODEPAGE` | `cp1251` |
| `MODEL_CONTEXT_SIZE` | `32768` |
| `MODEL_KEEP_ALIVE` | `-1` |
